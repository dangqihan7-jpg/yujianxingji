# 后端预留目录

当前没有可运行后端。拟使用 Node.js，版本和依赖在实施时固定。

建议接口（均未实现）：

- `GET /api/health`：服务状态，不返回密钥或配置值。
- `GET /api/places?keyword=...&city=...`：由服务端调用高德地点检索，限制长度、分页和允许的城市范围。
- `POST /api/itinerary`：接收目的地、天数、兴趣；返回结构化行程草案，明确模型输出需要校验。

前端通过同源 `/api/` 调用后端；开发环境代理规则待实现。模型与高德 Web 服务的密钥只保存在服务端。详细文件清单见 `docs/integration.md`。
