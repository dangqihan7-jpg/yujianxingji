# yujianxingji · 豫见行迹

面向讯飞杯展示的河南文旅路线助手项目骨架。计划围绕出行天数、兴趣与目的地，提供河南景点信息、地图展示和路线建议。

## 当前状态

本仓库目前提供项目说明、静态演示入口和后续接入约定。**尚未接入高德地图或任何模型服务，也没有实现景点检索、路线规划、实时导航、登录或数据持久化。** 页面中的地点仅用于说明展示场景，不代表推荐结果或可用行程。

## 功能范围

| 能力 | 状态 |
| --- | --- |
| 项目介绍与能力状态展示 | 已提供静态页面 |
| 景点查询与地图标记 | 待接入高德地图 |

## 技术栈

- 当前：原生 HTML / CSS，无构建依赖、无后端。
- 本地预览：Python 3 静态服务器（也可直接打开 HTML）。
- 后续拟采用：JavaScript 前端、高德地图 Web SDK、Node.js 服务端及模型 HTTP API。具体 SDK、服务商、模型和版本在接入时确认。

## 运行方式与演示入口

克隆仓库后，在仓库根目录运行：

```sh
python3 -m http.server 8000 --directory web --bind 127.0.0.1
```

打开 <http://localhost:8000>。按 Ctrl+C 停止服务。也可直接用浏览器打开 `web/index.html`，当前页面无需联网、安装依赖或配置密钥。

当前没有 `npm start`、构建流程、后端 API 或线上演示地址。展示说明见 [docs/demo.md](docs/demo.md)。

## 环境变量

当前静态演示不读取环境变量。`.env.example` 仅为后续接入提供配置约定；复制为 `.env` 不会自动启用地图或模型。后端实现后还需显式加载和校验变量。

| 变量 | 用途 | 可否出现在前端 |
| --- | --- | --- |
| `PORT` | 后端端口，拟为 3000 | 不需要 |
| `AMAP_JS_KEY` | 高德 Web 端 JS API Key | 可以，需配置来源限制 |
| `AMAP_SECURITY_PROXY_URL` | 地图安全代理地址 | 可以，仅地址 |
| `AMAP_SECURITY_CODE` | 高德安全密钥 | 否，仅服务端 |
| `AMAP_WEB_SERVICE_KEY` | 高德 Web 服务 API Key | 否，仅服务端 |
| `MODEL_BASE_URL` | 服务商 API 基础地址 | 仅服务端使用 |
| `MODEL_API_KEY` | 模型 API 密钥 | 否，仅服务端 |
| `MODEL_NAME` | 实际获授权的模型标识 | 仅服务端使用 |

不提交真实密钥，不把服务端 `.env` 放入 `web/`。详细待建文件及配置见 [docs/integration.md](docs/integration.md)。
