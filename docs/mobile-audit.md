# 手机适配与验收（2026-10-18）

本次只调整 767px 及以下的界面，沿用原生 HTML/CSS/JavaScript，没有新增 npm 依赖。桌面样式、地点数据和服务端接口契约保持不变。

## 调整范围

- `ui.css`、`decision.css`、`share.css`：新增样式全部包在 `@media(max-width:767px)`。输入框、下拉框、文本域计算字号至少 16px；按钮、链接、展开入口和复选框的关联标签提供至少 44px 触摸区域。
- 首页与规划：现有目的地城市、天数及生成入口可正常触摸；工具条、分日编辑和导出操作允许换行。
- 五智能体：完成后的五张来源卡纵向排列，实时步骤采用状态与内容两列，长标签和来源另起行；保留真实状态、减少动态效果与确认后应用流程。
- 时间线与分享页：375px 下保留 DAY、节点、站点卡和完整地点名；只读分享页没有编辑或 AI 入口，已有路由无需变更。
- 地图：图例位于地图下方；高德画布保留手势处理。无地图配置时，分布示意图在内部横向滚动，不扩宽页面，不将示意虚线描述为道路。
- `app.html`、`journey.js`：手机导出先打开生成/预览弹窗，完成后可长按图片、打开/下载图片；支持文件分享时显示“系统保存 / 分享”，由新的用户点击调用。取消或权限拒绝保留预览与后备入口；关闭后忽略迟到结果并回收图片地址。768px 及以上仍直接下载 PNG。

不能根据系统分享 Promise 的成功推断照片已经写入相册，因此只提示系统分享结束，不显示“已保存成功”。切到桌面断点时关闭手机预览，不让迟到的手机结果意外触发桌面下载；回到手机后可再次导出。

当前界面的城市选项是目的地，没有独立的出发城市字段。本轮按现有目的地控件完成验证，没有新增规划字段或改变接口。

## 验证方式

`npm run build`、`npm run validate`、全量 `npm test`（21 组，含新增移动导出测试）必须通过后才提交。单独运行移动导出边界与异常检查：

```sh
npm run test:mobile
```

新增 `scripts/test-mobile-export.mjs` 覆盖 375 / 390 / 414 / 767 与 768 / 1280 断点、预览与桌面下载、手势内文件分享、取消/拒绝/缺失 API、关闭和异步回收。原分享、海报契约、智能体流与回放测试保持通过。

浏览器使用本机 Google Chrome 和 DevTools Protocol 的尺寸/触摸模拟，覆盖 375、390、414px 的首页、需求表单、真实规则流水线的 SSE 步骤、确认后应用、时间线、海报 PNG 下载、分享弹窗和公开只读页；规则事件只在隔离测试传输层延迟以便观察，不虚构执行。补测 767/768 断点与 667×375 横屏。账号与分享数据使用隔离 SQLite，模型与外部地图调用被拦截；测试不耗用真实模型额度。

1280px 使用同一 Chrome、同一来源、固定时间、图片解码完成和禁用过渡的条件进行前后截图比较：首页、地图规划、行程总览及需求表单像素完全一致，未遮罩页面内容。

线上另用实际高德 SDK 在 375px 下核对：拖动后中心点改变，双指缩放后 zoom 改变，页面本身没有横向溢出；图例在 380px 地图下方。仅允许配置与地图素材读取（含官方瓦片读取 POST），拦截所有应用写入接口；未调用模型或新增分享。

Chrome 模拟不等于真实 iOS Safari。输入字号与聚焦缩放已按浏览器计算样式检查，原生分享的成功、取消、拒绝和无 API 分支由浏览器/单元测试验证；iPhone 上实际系统分享面板与写入相册仍需真机复核。没有通过禁用用户缩放来规避输入问题。
