# 对话式单日行程调整

## 使用方式

在地图规划页点击“和 AI 调整这一天”，或在规划/总览的“问 AI”抽屉中进入调整。

1. 选择要调整的日期，勾选这一日必须保留的地点。
2. 输入要求，例如“这一天太赶了，减少一站，保留龙门石窟”。
3. 查看修改前后站点、停留分钟数、增加/移除/排序/停留时长变化，以及未确认事项。
4. 点击确认后才载入；关闭窗口不修改原行程，应用后可使用原撤销按钮恢复。

一次调整一天，其他天的地点、顺序、时长保持不变。不会自动修改预算目标、出行方式或旅行天数。新增地点限目标日已有城市中的河南精选目录；空白日期需有明确的单城目的地。锁定日期的地点、必去地点与本次勾选保留地点受程序保护。高德搜索加入的地点可以保留与重新排序，不会由模型凭空生成新的外部地点。

原问答接口仍然只读。这是独立的模型局部调整建议，不展示五阶段假进度，也不声称执行了新一轮完整五智能体流水线。用户可在确认后，基于新行程再次发起调整；不在服务器保存对话历史。

## 接口与配置

`POST /api/revise`，前端请求体示例（`draft` 为已有行程快照对象）：

```js
const body = {
  instruction: '这一天太赶了，减少一站，保留龙门石窟',
  targetDay: 2,
  draft: compactDraft(),
  keepIds: ['hn-longmen']
};
```

要求为 1–600 字；日期必须存在，保留 ID 必须属于选定日期。候选通过验证后返回 `source`、`provider`、`targetDay`、`draft`、`changes`、`audit`、`note`。`changes` 由程序比较原行程与候选计算，包含新增、移除、停留时长变化、是否重排，以及前后站数和停留分钟合计。

复用已有 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 和 Spark 请求实现，不新增密钥、不修改其他模型接口。复用规划服务的身份与演示额度：未开放公共模型演示时需要登录；开放公共演示时与规划共用 `LLM_DAILY_LIMIT` / `LLM_CLIENT_DAILY_LIMIT`，失败尝试计数。只有手动生成建议才调用一次模型，不自动重试。

校验不通过返回 400，未获模型访问权限返回 403，额度耗尽返回 429，未配置或额度服务不可用返回 503；上游失败、超时或违反候选约束返回 502。原行程不因服务端成功或失败而改变，服务端不写用户草稿。

模型上下文只包含本次要求、所选日期、精简行程、保留要求和可用目录，不转发账号、体验记录、原草稿私密元数据或凭证。

## 数据真实性与并发保护

- 前后分钟数只统计停留时间，不冒充完整出行耗时、节省交通时间或步行距离。
- 不编造票价、营业、预约、天气、无障碍条件或交通保证；变化后的交通与费用需重新核对。
- 原草稿、输入要求、所选日期或保留项改变后，旧候选不能应用。
- 关闭窗口、切换页面或取消时终止等待；迟到响应不重新打开窗口、不覆盖新行程。
- 应用前再次调用原 `/api/validate`，并检查原草稿指纹；使用现有撤销和保存机制。
- 手机输入字号不少于 16px，操作目标至少 44px；减少动态效果时关闭入场动画。

## 验证

运行顺序：

```sh
npm run build
npm run validate
npm test
```

新增接口与 UI 测试使用模拟上游，不消耗真实讯飞额度。真实模型对自然语言要求的理解质量需使用已配置的服务另外验收；模拟测试不能代替此验收。

手动验证：准备至少两天行程，给目标日设置一处锁定/保留地点，输入减少行程的要求。确认生成候选时原行程不变；对照其他日期未改、保留地点仍在、实际差异与预览一致，再确认并检查撤销。关闭窗口或在请求未结束时修改条件后，旧响应应失效。未配置模型时应显示明确提示，原手动规划仍可用。

### 2026-10-31 本地结果

- `npm run build`、`npm run validate` 与完整 `npm test` 全部通过（32 个测试脚本）。新增接口测试 21 组、UI 测试 15 组。
- 隔离本地服务器通过真正的 `/api/revise` 路由与校验器，模拟 Spark 上游。输入“第二天轻松一点，保留白马寺，少安排一站”：候选将该日从 3 站/270 分钟停留变为 2 站/150 分钟停留；生成时全行程仍为 5 站，确认后为 4 站，第一天不变；撤销恢复 5 站。这些数值是测试夹具结果，不是实际模型效果或交通节省结论。
- 浏览器检查 375、390、414、1280px：页面无横向溢出；手机对比单列、桌面对比双列；输入字号 16px、按钮最小高度 44px。候选审计区只读，不显示会操作现有草稿的重排/交通按钮。
- 本次没有调用真实讯飞模型、没有更改地点照片、没有执行服务器部署。真实自然语言理解和线上响应质量待使用现有已配置服务验收。
