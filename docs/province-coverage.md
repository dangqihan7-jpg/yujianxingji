# 河南全省旅行目录

更新：2026-10-12。覆盖 17 个省辖市及济源，共 18 个市级旅行目的地、95 个精选地点、20 条示例路线。数量表示本项目精选目录，不代表河南全部景区。

## 已实现

- 十八城首页入口、旅行片区筛选、城市/县域/景点名称与别名搜索；城市详情包含主题、美食方向、三个代表地点、资料来源和两日示例。
- 城市目录用于地图筛选、规则与模型条件校验、草稿保存校验、API 和离线版；县域名称识别到所属旅行城市。
- 每城至少四个精选地点、一个两日路线，保留原有跨城经典组合。选择路线只预览，载入需要用户主动操作。
- 参考定位保留高德点位链接、地址、行政区与说明；导航入口和真实道路交通仍需用户确认。

## 数据边界

1. 95 个地点包含景点、村落、公园及夜市等，不是 95 家已审核的开放景区。现有 12 张实景保留来源、作者、许可和日期；本次没有新增照片。缺图地点使用文字示意，路线不会借用其他地点封面。
2. 停留时长与两日组合是编辑建议。县域山水另需确认往返、索道、景区内部交通、天气与门票。商丘—永城、南阳—县域、信阳—鸡公山等转场有明确提醒，不包含未经查询的实际交通。
3. 大南坡村使用村委会、郝堂村使用居委会、浚县古城使用古城保护建设服务中心的参考位置，不等于游客入口。濮阳龙湖使用湖泊点，不把湖中心当成停车場。其余 POI 也须匹配正确入口后才能用于交通核算。
4. 核对时高德把开封市博物馆、豫西大峡谷标为暂停开放；设置 `planningEligible:false`，保留资料和待确认说明，暂不加入首页代表地点、示例路线或自动候选。这不宣称永久关闭，恢复前须再次确认运营方信息。
5. 资料来自政府文旅公告和景区官网，不保证所有网页刚刚更新。`contentCheckedAt` 是本项目核对日期，不是照片拍摄日期或实时营业日期；票价、预约、演出和住宿须出发前确认。
6. 高德实时美食和住宿查询沿用原接口；用户照片不应统称人工审核过。洛邑古城出现西安图片的报告仍缺具体截图，尚未复现，不宣称已修复。

## 维护方式

城市在 `henan.json.cities`，地点在 `places`，路线在 `routes`。新增或修改时：

1. 保持唯一固定 ID，正确的市级归属与县域地址，明确类别、建议时长、兴趣、必要别名、原创介绍及玩法提示。
2. 保留资料 `reference`、核对日期 `contentCheckedAt`、高德参考点 `locationReference`、`district`、`locationNote`；不把行政参考点写成售票入口。
3. 更新城市 `highlights`、`routeId`。代表地点属于本城，暂不推荐的地点不加入代表或示例；路线地点 ID 必须存在，封面只来自自身路线地点。
4. 图片按 [照片维护](photo-maintenance.md) 核对作者、许可、拍摄时间、来源与本地文件。无合适合法图片时保持文字展示。
5. 执行 `npm run build`、`npm run validate`、`npm test`，检查全城 API、县域别名、排除条件、停业待确认、路线与草稿保留，再验证电脑/手机。构建为前端、服务端和离线版注入同一城市数据。
6. 同步源码与生成 Worker，备份代码和 SQLite 后更新服务器，保留密钥、数据目录与 `.local` 链接。离线页、构建输出、数据库及临时报告不提交。

## 验证入口

- `/api/catalog`：18 个城市名称、城市指南、95 个精选地点及 20 条路线。
- `/api/places?city=信阳`：高德服务未配置时返回精选；在线服务启用后可返回实时查询，前端精选仍使用本地目录。
- `/api/places?city=河南&q=胖东来`：全省精选别名查询。
- 首页“探索河南18城”与路线选择器；离线页包含相同目录和规则，道路地图及在线搜索需联网。
