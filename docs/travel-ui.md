# 旅行氛围与交互动效

本项目继续使用原生 HTML/CSS/JavaScript，不引入 React、Vue、字体包或新的运行依赖。页面作者文件由 `scripts/assemble.py` 组装，完整部署入口为 `worker/index.js`；不要只修改生成文件。

## 文件与运行

- `ai-hero.js` / `ai-hero.css`：沉浸式风景与悬浮 AI 输入、相机入口和五智能体能力。
- `travel-theme.css`：深藏青、青绿、日落橙的全站样式，照片卡片与玻璃层次。
- `travel-motion.js`：滚动进入、真实结果逐段显示和操作微反馈；不接管业务处理。
- `showcase.js`：保留每日十图、城市探索和灵感路线；旧照片展示区继续可用。
- `scripts/test-travel-hero.mjs` / `scripts/test-travel-motion.mjs`：新增入口与动效回归。

安装后执行 `npm run build`、`npm run validate`、`npm test`，再用 `npm run dev` 启动。本地默认地址 `http://127.0.0.1:8787/`。可执行 `node scripts/offline.mjs` 生成照片嵌入的 `index-offline.html`；离线版使用明确标注的规则候选，不能访问真实模型、分享或图片理解服务。

## 照片与信息真实性

沿用现有已审核的河南实景，不随机用其他城市的照片替换地点图片。原始照片文件、地点数据、作者、拍摄时间与许可没有改动，完整来源仍可从照片说明和相册访问。背景的暗色渐变属于页面叠层，不对原始照片改色或重编码。缺图及图片加载失败保留“照片占位”标识。每日精选日期不冒充拍摄日期。

## 动效边界

动效仅改变 `transform` 和 `opacity`，使用 `cubic-bezier(0.2, 0.7, 0.2, 1)`。阴影、描边与玻璃模糊是静态样式或通过伪元素透明度显示，不对模糊半径或阴影数值连续插值。减少动态效果用户直接显示内容；没有 IntersectionObserver 时仍能正常阅读，不以动效为功能前提。

智能体的实际步骤继续由已有 SSE 与 JSON 降级路径提供。最终候选的分日、理由等真实内容使用逐段入场，不编造思考文本、进度或耗时。段落动效不改变后端返回值、`hidden` 状态、回放顺序或确认后应用门禁，不额外触发模型请求。选择、加入等反馈复用既有操作；没有新增虚构的收藏或保存结果。

移动端保持至少 44px 点击区域和至少 16px 输入字号，规划、地图、时间线、图片识别、海报及分享入口保留。地图瓦片和导出图片的数据逻辑保持原样。

## 改动与解决的问题清单

1. 沉浸式真实风景、由下至上的深色遮罩：让第一屏具有旅行氛围，保持标题和 AI 输入清晰可读。
2. 深藏青底、青绿主色与少量日落橙：替代大面积白底，统一首页、规划和弹窗层级。
3. 圆角照片卡片、底部半透明标题和玻璃面板：加强目的地吸引力与前后层次，保留缺图诚实占位。
4. 响应式标题与弱化的辅助文字：建立主次，避免小屏标题或表单挤压。
5. 输入聚焦光晕、按钮上浮/按压、照片缓慢放大：让可输入、可点击区域获得明确反馈。
6. 滚动淡入上飘与真实结果逐段入场：增加浏览节奏，不改变业务数据或伪造 AI 执行。
7. 选择与加入微反馈、减少动态效果和无观察器降级：兼顾操作确认、可访问性与性能。
