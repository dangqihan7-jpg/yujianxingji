# 首页语音输入：协议与验收记录

## 功能与配置

首页点击“语音输入”申请麦克风权限，再点“结束录音”上传。识别结果追加到点击完成时输入框的现有文字后，保留编辑能力，不自动调用规划。最长60秒；超过600字容纳空间时保留原文并展示完整识别文字供复制，不静默截断。

原始16kHz、16bit有符号小端、单声道PCM（非WAV/WebM/MP3），`POST /api/stt`，`Content-Type: application/octet-stream`，最大1,920,000字节。成功只有 `{"text":"识别文字"}`。空音频400、未配置503、上游错误或超时502、超限429、超大413、不支持的方法405。取消请求408。服务端不存储音频或识别文本，只保存额度计数。

服务端配置 `XF_ASR_APPID`、`XF_ASR_APIKEY`、`XF_ASR_APISECRET`，三项需来自同一个已开通**语音听写（流式版）**的应用。只放在服务器 `/etc/yujianxingji.env`（权限600），不进浏览器、源码、日志或报告。填写后执行 `systemctl restart yujianxingji`。仓库 `.env.example` 仅有空变量。

[讯飞官方流式听写文档](https://www.xfyun.cn/doc/asr/voicedictation/API.html)指定 `wss://iat-api.xfyun.cn/v2/iat`；签名参照现有识图模块的HMAC-SHA256机制。音频每帧1280字节、按40ms实时节奏发送，第一帧0、后续1、最后空帧2；按结果序号累积首选文字，未启用动态修正。未收到完整结果不展示成功；长停顿导致上传未完成就结束时提示分段重试，不悄悄丢掉后半段。整体85秒、握手8秒上限，前端总等待100秒。60秒录音录完后仍需等待逐帧上传，界面此时显示“AI 正在识别…”。

限流复用 `model_usage`，`stt:`独立scope，按UTC小时整点重置：匿名3次、登录用户10次、全局100次。仅合法、已配置且获配额的上游尝试计数，上游失败也计数。没有数据库时拒绝服务，不降为无限量。

## 自动检查范围

- 后端：模拟上游WebSocket、真实隔离SQLite迁移；未配置、空音频、PCM大小/格式、签名、分片/终帧、分片结果顺序与去重、60秒边界、上游错误/超时、取消、匿名/登录/全局小时限流、跨小时重置、并发及隐私保护。
- 前端：模拟麦克风、AudioWorklet/ScriptProcessor、44.1/48kHz重采样、PCM字节序、60秒自动截止、已有文字追加、无自动提交、超长保留、权限拒绝、不安全上下文、页面隐藏/切换/重绘清理、迟到权限与网络响应、音频启动与识别超时。
- 全量测试在独立副本运行，`competition-evidence` 时间戳文件不写原工作区或提交。
- 模拟麦克风和模型不等于真人录音识别准确率，不拿自动测试替代下述真人验收。
