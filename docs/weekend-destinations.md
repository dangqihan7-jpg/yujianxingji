# 周末目的地补充（2026-10-11）

由仅偏重古迹、博物馆的展示，补充武侠演艺、山区登山、亲子乐园和电影夜游。目录新增以下四处，合计 26 个地点；首页“这个周末，换个玩法”可查看详情或预填旅行需求。点击规划仍需确认条件与候选，不自动替换草稿。

| 地点 | 位置与体验 | 公开资料 |
|---|---|---|
| 万岁山武侠城 | 开封龙亭区；武侠实景演艺与角色互动 | [河南省文旅厅](https://hct.henan.gov.cn/2025/09-24/3229991.html)、[高德西侧入口](https://www.amap.com/place/B0FFH1RM9R) |
| 老君山 | 洛阳栾川；峰林、栈道与金顶道观群 | [景区官网](https://www.laojunshan.cn/)、[高德地点](https://ditu.amap.com/place/B017B01NH7) |
| 银基动物王国 | 郑州新密；动物观赏、游乐与演艺 | [度假区官网](https://www.enjoyland.cn/ScenicSpots-1.html)、[高德地点](https://amap.com/place/B0FFKYGE2W) |
| 建业电影小镇 | 郑州中牟；电影主题街区和沉浸式演艺 | [河南省文旅厅](https://hct.henan.gov.cn/2025/09-24/3229991.html) |

精选方向不等于实时热度排名，也不代表新开业。没有写死票价、演出场次或开放时间。游览时长是安排建议；实际交通、排队、索道与票务请进一步确认。老君山需要单独留出一天，行程检查会持续提示往返栾川、索道排队及下山时间尚需核算。

地图坐标为片区展示：万岁山参考西侧入口，老君山参考景区点位，银基参考动物王国；电影小镇采用约 114.00E、34.78N 的中牟片区位置。全部沿用确认高德交通入口后再核算的流程。

需求规则与搜索支持“万岁山”“大宋武侠城”“栾川老君山”“电影小镇”等别名，同时保留否定条件识别。只提到一个必去地点时，规则可据目录补出所属城市。增加“沉浸演艺”和“亲子乐园”兴趣，候选排序按兴趣匹配，匹配分相同时优先本次精选方向。万岁山不会因名称含“山”就被当成山水登山目的地。
